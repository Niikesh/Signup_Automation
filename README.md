# Signup Automation Script

# Overview
This repository contains an automation script for testing the "Signup flow". It includes the script, test report, and demo video.

---

# Environment / Setup

- Language: Python 3.11.4
- Framework: Playwright 1.36.0
- Test unit : Pytest 7.4.4
- Browser Driver: ChromeDriver 135.0.7049.84

---

# Getting Started

1. Clone this repository:
   
   git clone https://github.com/Niikesh/Signup_Automation.git
   
   cd Signup_Automation

3. Install required dependencies

    pip install -r requirements.txt

4. Run the automation tests

    pytest -v signup_automation_script.py
